## О проекте

DZEN — одностраничный сайт парикмахерской студии. Здесь можно познакомиться с услугами, выбрать подходящие процедуры и перейти к записи.

## Возможности

- Каталог стрижек, уходов, пакетов и укладок
- Интерактивный выбор услуг
- Подбор ухода и форма записи
- Светлая и тёмная темы
- Адаптивный интерфейс для мобильных устройств
- Анимации с поддержкой настройки `prefers-reduced-motion`
